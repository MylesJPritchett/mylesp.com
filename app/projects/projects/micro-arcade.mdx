This is a showcase of micro games I built with a one-button control scheme.

They are made using the
[crisp-game-lib](https://github.com/abagames/crisp-game-lib)
and are meant to just be fun and unpolished. The games are all made in
simple JavaScript. There are nine so far, from Dodge, my first, to Duel, where
you tap to stab, hold to block and release to parry.

The main purpose of these games is to experiment and design around limitations,
and to have such small scope that I can finish a game in only an hour or two.

I want to be able to quickly prototype a new idea without getting bogged down
in details. I think getting practice making tiny games is a good way to filter
out the good ideas from the bad ones.

This hopefully will help keep motivation high, as I can quickly see results from
my efforts and share them with friends.

If I have a bad idea, it took almost no time to make, so I can just move on to
the next idea without feeling like I've wasted a lot of my time.

The arcade's home page, with a preview and high score for each game, is
generated at build time by a small script that finds every game folder, so
adding a game needs no other changes.

# mylesp.com

Myles Pritchett's personal site: the public showcase a recruiter or hiring manager reads to decide whether to get in touch.

## Language

**Portfolio**:
The whole site, taken as a single showcase of who Myles is and what Myles has built.
_Avoid_: Using "portfolio" for the list of Projects

**Project**:
One piece of work Myles has built and chosen to show, with a write-up, source and optionally a live link.
_Avoid_: Portfolio item, portfolio project, work

**Featured Project**:
A Project Myles has chosen to rank near the top because it best shows Myles' ability, regardless of when it was made.
_Avoid_: Pinned, highlighted

**Stack**:
The technologies a Project is built with, grouped into Layers.
_Avoid_: Tech, tools, tags

**Layer**:
One part of a Stack: Frontend, Backend, Data, AI, Infra or Testing. A Project lists only the Layers it uses.
_Avoid_: Tier, category

**In Progress**:
The status of a Project Myles is still actively building, shown so readers expect it to change.
_Avoid_: WIP, beta, draft

**Post**:
One dated piece of writing on the blog.
_Avoid_: Blog, article, entry

**Experience**:
A paid role Myles has held, with employer, dates and outcomes.
_Avoid_: Job, work history, employment
